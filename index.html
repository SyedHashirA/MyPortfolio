IoT / EMBEDDED

Smart Gas Leakage Detection (GasGuard)

An ESP32-based LPG detector solving what most DIY detectors ignore: environmental calibration.

ESP32 Arduino Blynk
Details

The Problem

Most DIY gas detectors hard-code a single threshold. This works in a controlled test but fails in real homes — humidity, temperature, background VOCs, and sensor-to-sensor variation all shift the baseline. Result: false alarms or missed leaks.

The Solution

  • Auto-calibration — measures each home's clean-air baseline over 60s on first boot
  • User-adjustable sensitivity — tuned live via the Blynk IoT app
  • Rate-of-rise detection — +20 jump within 1s triggers the alarm
  • Hysteresis recovery — prevents alarm flickering near threshold
  • Active air sampling — 5V fan with sheet diffuser cuts response from 10–30s to 2–5s
  • Fire-alarm buzzer pattern — 3000 Hz + 2500 Hz alternating
  • Servo-driven shutoff — SG90 rotates 90° to close a gas valve
  • IoT dashboard — live readings and controls via Blynk

Key Engineering Decisions

  • Auto-calibration over fixed thresholds
  • Rate-of-rise over pure threshold
  • Active air sampling for faster response
  • Hysteresis on recovery for smooth UX

Tech Stack

ESP32 MQ-6 Sensor SG90 Servo Blynk IoT Arduino (C++)

Status

IoT / EMBEDDED

Fault-Tolerant Smart Home Automation

A 4-tier redundant IoT control system that eliminates the single point of failure in WiFi-only smart homes.

ESP32 BLE C++
Details

Overview

Most smart home devices rely solely on WiFi — so when the router drops, the entire system goes dark. I designed and built a 4-tier redundant IoT control system that eliminates this single point of failure.

Four Independent Control Paths

  • WiFi via Blynk — cloud control, highest priority
  • Bluetooth Low Energy remote — local short-range fallback
  • IR remote — zero-pairing, deterministic physical fallback
  • Offline voice recognition (AI VC-02) — hands-free, no internet needed

How It Works

A priority-based arbitration scheme keeps all four listeners active simultaneously — no switching, no re-initialization. If WiFi fails, BLE takes over instantly; if BLE fails too, IR and voice keep the system fully operational.

Key Results

  • 100% failover success across 400+ controlled trials
  • <300 ms average failover latency (6× faster than sequential solutions)
  • 95% offline voice recognition accuracy across 150 commands
  • Graceful degradation: Normal → Degraded → Fallback with zero user intervention

Tech Stack

ESP32 C++ BLE WiFi IR UART Blynk PlatformIO

Takeaway

"Reliability isn't a feature you add later — it's an architectural decision."
